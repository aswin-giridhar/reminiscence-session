# Configuration template

The Skill needs **no credentials, API keys or settings files**. Its only "configuration" is the information a carer gives in a request. Copy this template, replace each placeholder in square brackets, and keep it somewhere private on the NAS.

All values below are placeholders. Do not put real medical details here.

## Person profile (reused every session)

| Field | Value | Notes |
|---|---|---|
| Person's name as the carer says it | [e.g. Mum] | Used only in memory-book text |
| Birth year | [YYYY] | Sets the music window: birth year + 10 to + 25 |
| Session folder on the NAS | [NAS folder you created] | Memory books and journal entries are saved here |
| Language of voice notes | [en / de / ja / zh / other] | Needed for transcription |
| Avoid list | [people, places or topics that cause distress] | Always excluded; journal "Distress" items are added automatically |

## Per-session request

| Field | Value | Notes |
|---|---|---|
| People | [names exactly as in the photo app's person albums] | Optional if years or a place are given |
| Years | [start YYYY] to [end YYYY] | Write four-digit years explicitly |
| Place | [place name] | Optional |
| Number of photos | [e.g. 12] | Default proposal is 12 |

## Example request built from the template

> Prepare a memory session for [Mum], born [1950], about [Jean], [1970] to [1979], [12] photos. Avoid [Arthur]. Save to [session folder].
