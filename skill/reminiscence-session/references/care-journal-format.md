# Care journal format

Each Log run saves one new Markdown file in the session folder. The filename starts with `care-journal`, and the save action adds a timestamp. Earlier entries are never edited or deleted, so the history stays complete.

```markdown
# Care journal: (session theme)
Session date: (date) · Memory book: (book file name)

## Responded well
- song: (title), (artist)
- person: (name)
- place: (place)

## Neutral
- photo: picture ID (id)

## Distress
- person: (name)
- place: (place)

## Other notes
- (anything the carer said that could not be linked)
```

## Reading rules (Prepare, step 1)

- Read the 5 newest entries at most.
- Every "Distress" item joins the avoid list for the new session.
- A "Responded well" item counts as a preference. If a later entry lists the same item under "Distress", the newer entry wins.
- If an entry does not follow this format, ignore its lists and tell the carer which file could not be read. Do not guess its contents.

## Privacy

Entries are plain text in the family's own NAS folder. They contain only what the carer said. Nothing is sent outside the NAS.
